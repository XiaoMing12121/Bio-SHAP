# Bio-SHAP · Windows 版安装说明

## 两个文件选哪个？

| 文件 | 适合谁 | 说明 |
|---|---|---|
| `Bio-SHAP-win64-1.0.0.zip` | 所有人都能用 | 解压后双击 `Bio-SHAP.exe` 即可运行，无需安装 |
| `Setup-Bio-SHAP-1.0.0.exe` | 想要"正规安装"的用户 | 安装向导，可自选安装盘/目录，生成开始菜单和桌面快捷方式 |

## zip 版使用步骤

1. 解压到任意目录（如 `D:\Bio-SHAP`，建议不要放桌面）；
2. 双击 `Bio-SHAP.exe`；
3. 首次启动会弹出激活窗口 → 把设备码发给作者 → 粘贴收到的激活码 → 点击激活。

## exe 版使用步骤

1. 双击安装程序 → 一路下一步（可改安装位置）→ 完成；
2. 从开始菜单或桌面快捷方式启动；
3. 激活方式同上。

## 常见问题

- **杀毒软件误报**：程序用 PyInstaller 打包、无数字签名，个别杀软会误报。添加信任即可，介意请先试用 zip 版。
- **激活码有效期**：默认 1 年，到期后向作者续期即可。
- **卸载**：zip 版直接删文件夹；exe 版到"设置-应用"卸载。

## 系统要求

- Windows 10 / 11（64 位）
- 无需安装 Python 或其他依赖
