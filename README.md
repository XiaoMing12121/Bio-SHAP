# Bio-SHAP —— 输入数据，直接出图

**Bio-SHAP** 是一款面向科研人员的桌面制图软件：把表格数据丢进去，一键出
**可发表的 SCI 级图表**。Windows / Linux 双平台，本地可视化窗口，无需写一行代码。

## 它能画什么（16 类图）

**生信基础**：火山图、热图、PCA 降维、箱线/小提琴图、相关性热图
**分类诊断**：ROC/PR 曲线、校准曲线、回归诊断
**机器学习解释**：SHAP 蜂群图、SHAP 特征重要性、学习曲线、验证曲线、
特征重要性条形图、指标-阈值曲线、混淆矩阵
**深度学习**：训练曲线（loss/acc 多序列）

支持 PNG / SVG / PDF 导出，600dpi 可发表级输出，matplotlib 缩放工具栏，默认中文字体。

## 数据怎么喂

支持表格、CSV、粘贴文本三种输入；每类图都有示例数据（软件内一键加载），
照着示例把数据替换成自己的即可。

## 激活方式

一机器一码：首次启动显示设备码 → 联系作者获取激活码 → 在线激活。
默认有效期 1 年，到期续期。离线证书导入亦可激活。

## 下载

- **Windows**：`Windows/Bio-SHAP-win64-1.0.0.zip`（解压即用）或
  `Windows/Setup-Bio-SHAP-1.0.0.exe`（安装向导，可选安装盘）
- **Linux**：见 `Linux/Linux安装说明.md`（GitHub Actions 自动构建或本地构建）

## 常见问题

- 无需安装 Python / R，开箱即用；
- 杀毒软件误报：打包程序无数字签名，添加信任即可；
- 激活问题：联系作者，提供设备码即可。
